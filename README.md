This project is a simple Windows utility to view a folder on the local PC with multiple GPX files at once and view them on a map. 

<img alt="image" src="https://github.com/user-attachments/assets/3a439cb6-29cd-49d8-9b8b-f27fdb575678" />

You can download and run the installer (GPX-View-Setup.exe) from [releases](https://github.com/jroal/GPX-View/releases).

More details and source on Github: [https://github.com/jroal/GPX-View](https://github.com/jroal/GPX-View)

Project website: [https://jroal.github.io/GPX-View/](https://jroal.github.io/GPX-View/)

Video demo: [https://youtu.be/Ul8_T19j_QU](https://youtu.be/Ul8_T19j_QU)

If you don't have a Windows PC, or you just prefer a simple web app, use this web version: https://jroal.github.io/GPX-View/gpx-view-web.html
